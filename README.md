# 91.3 Ayclt FM — IPTV, TV & XMLTV Guide

**La Marque TX #1 Hit Music Station**

This repository publishes the official IPTV playlist and electronic programme guide (EPG) for 91.3 Ayclt FM and its associated channels. The playlist includes live TV streams, while the XMLTV and JSON files provide programme schedules for compatible IPTV players and media servers such as Jellyfin and Plex.

## EPG generation

The EPG is generated by `generate_epg.py` using the AzuraCast schedule and streamer APIs.

- **Guide length:** 7-day rolling window
- **Timezone:** `America/Chicago` (Central Time)
- **Refresh workflow:** every 5 minutes
- **Schedule retrieval:** requests up to 1,000 entries per API request and fetches the guide window in date chunks
- **Gap handling:** adds filler programmes where the schedule has no entry; filler blocks follow hourly boundaries where possible

The rolling window start is rounded down to the current 5-minute interval. A successful run can therefore advance the guide window in 5-minute steps.

## Channel artwork

The XMLTV generator publishes a channel-level icon for every channel. Programme entries also include artwork when available.

- Main station, HD2, and HD3 use their configured station artwork.
- Gaming Central Radio uses its configured station artwork.
- Both studio camera channels use the main 91.3 Ayclt FM artwork for every programme, including live shows.
- LIVE DJ/streamer programmes on the radio channels use the current AzuraCast streamer artwork when it can be resolved.

## Automatic DJ / streamer artwork

The generator discovers streamer names and IDs from each station's AzuraCast Streamers API. It builds the lookup dynamically rather than relying on a manually maintained DJ ID list or a local artwork cache.

When a LIVE DJ's artwork cannot be resolved, the programme is left without a programme-level icon rather than being assigned potentially incorrect DJ artwork.

## LIVE programme metadata

LIVE DJ/streamer programmes are marked in XMLTV with:

```xml
<live/>
<category lang="en">Radio Show</category>
<sub-title lang="en">LIVE</sub-title>
<new/>
```

The programme title is kept clean; the generator does not add a `[LIVE]` prefix. The studio camera channels mirror the main station's schedule and LIVE state.

The XMLTV file supplies metadata, but the IPTV/Jellyfin client controls whether and how a graphical LIVE badge is displayed. Different Jellyfin clients may display this metadata differently.

## Automatic GitHub Actions updates

Workflow: `.github/workflows/update-epg.yml`

The workflow is configured to run:

- Every 5 minutes (`*/5 * * * *`)
- When `generate_epg.py` or the workflow file changes on the repository's default branch
- Manually through **Actions → Update 91.3 Ayclt FM EPG → Run workflow**

Each run:

1. Checks out the repository and sets up Python 3.12.
2. Checks Central Time daylight-saving timestamp handling.
3. Retrieves AzuraCast schedules and streamer directories.
4. Generates the 7-day XMLTV and JSON guides.
5. Validates XML, JSON, channel coverage, playlist/XMLTV IDs, programme timelines, and LIVE metadata.
6. Commits the generated XMLTV and JSON files when their contents change.

GitHub controls when scheduled jobs start, so a scheduled run may begin later than its requested minute. A new EPG commit is created only when the generated files have changed; no new commit does not necessarily mean the workflow did not run.

| Station | AzuraCast station slug |
|---|---|
| 91.3 Ayclt FM | `91.3_ayclt_fm` |
| 91.3 Ayclt FM HD2 | `91.3_ayclt_fm_hd2` |
| 91.3 Ayclt FM HD3 | `91.3_ayclt_fm_hd3` |
| Gaming Central Radio | `gaming_central_radio` |

Configure these GitHub Actions repository secrets when required:

| Secret | Purpose |
|---|---|
| `AZURACAST_API_KEY` | Shared AzuraCast API credential |
| `AZURACAST_CA_CERT` | Optional PEM CA certificate chain if the AzuraCast origin uses a private or self-signed CA |

The API key is supplied to the workflow as an environment variable and is not stored in the repository source. TLS certificate verification remains enabled; the generator does not disable certificate checks.

1. Add an **M3U tuner** in Jellyfin.
2. Use the playlist URL:

   `https://raw.githubusercontent.com/913AycltFM/91.3-Ayclt-FM-TV/main/91.3_Ayclt_FM_radio_playlist.m3u`

3. Configure an XMLTV programme guide provider using:

   `https://raw.githubusercontent.com/913AycltFM/91.3-Ayclt-FM-TV/main/91.3_Ayclt_FM_radio_guide.xml`

4. Save the configuration and refresh the Live TV guide data.

Use the equivalent playlist and XMLTV URLs in other IPTV applications that support M3U and XMLTV.
